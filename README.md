# Laser CNC Simulator

Interactive simulation of a CNC laser cutting machine developed in Unity.

## Overview

This project simulates the operation of a CNC laser cutting machine in a virtual environment. It was originally created as a graduation project focused on machine visualization and operator training.

The simulator includes interactive machine controls, animated mechanical components, and a modular scene architecture suitable for further expansion.

## Features

* Interactive CNC laser machine simulation
* Animated laser head movement
* Modular machine component hierarchy
* Camera control system
* Operator interaction system
* Blender-based 3D asset pipeline

## Technologies

* Unity
* C#
* Blender
* FBX asset pipeline

## Project architecture

The simulation is organized into independent systems responsible for machine movement, interaction, camera control, and visualization.
